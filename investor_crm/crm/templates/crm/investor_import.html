Import from Excel

Upload an .xlsx file. The first row must be column headers. Each Investor name is processed once per file (case-insensitive): later duplicate rows for the same name are skipped. Existing database records are updated; new names are created. Large files (~1,500+ rows) are supported with batched lookups.

Expected columns

  • Investor — name (required)
  • Type — e.g. Asset manager, Bank (must match app types)
  • Contact or Principal contact(s) — principal contact
  • Website — URL (https added if missing)
  • Status — one or more labels separated by commas (e.g. Target for SMA, Revisit)
  • Ticket size (£m) — number
  • Meeting / Zoom — Yes/No
  • VDR — Yes/No
  • Office — office name (created if new)
  • Prefequity resp. — TD, NP, JCP, TB, or PW (sets responsibility to Prefequity)
  • Intermediary — intermediary name (sets responsibility to Intermediary; overrides Prefequity if both filled)
  • Comment — maps to About
